# CinemaTest
Meu primeiro projeto de automação de testes com Jest.

# Sistema de Automação de Testes - Cinema & Descontos
1. O que é este projeto?
Este projeto foi desenvolvido para demonstrar a aplicação de Testes de Unidade e Análise de Valor de Limite em regras de negócio críticas, como classificação indicativa e cálculo de descontos progressivos.

# Tecnologias Utilizadas
JavaScript (Node.js)

Jest (Framework de Testes)

Git & GitHub (Controle de versão e documentação)

# Desafios de Lógica Resolvidos
Neste repositório, foquei em dois cenários onde bugs costumam causar prejuízos ou problemas legais:

Classificação Indicativa: Garante que o sistema barra menores de idade em filmes restritos, testando o limite exato de 18 anos.

Cálculo de Desconto: Valida se o desconto de 10% é aplicado corretamente em compras a partir de R$ 100,00, corrigindo falhas comuns de operadores lógicos (> vs >=).
